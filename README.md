# Modsen Calendar

Календарь событий с возможностью управления событиями, поиском мероприятий через внешнее API, drag-and-drop и сохранением данных в localStorage.

## Технологии

- React 19 + TypeScript
- Vite – сборка проекта
- SCSS – стилизация
- Axios – HTTP-запросы к API
- date-fns – работа с датами
- @dnd-kit – drag-and-drop для событий
- react-error-boundary – обработка ошибок

### Качество кода

- ESLint + Prettier – линтинг и форматирование
- Husky + lint-staged – pre-commit хуки
- commitlint – проверка формата коммитов (Conventional Commits)
